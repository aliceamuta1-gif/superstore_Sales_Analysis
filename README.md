# Superstore Sales Analysis
## Project Overview
this project analyzes retail sales performance using Excel,SQL,Python,Tableau,and Power BI.
The objective was to clean,analyze and visualize sales data to identify trends,profitability drivers and business opportunities.
##Tools Used
-Sql
-Excel
-Python
-Tableau
-Power BI
